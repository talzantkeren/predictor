# ראיית מסירה — S9-DEF-018

## תוצאה

`VERIFIED` — שורת RPC ‏`NOT_DUE/FORCE_COOLDOWN` מתקבלת בחוזה TypeScript
ומוחזרת כ־`skipped` ניטרלי. orchestration אינה קוראת לספק, apply או finalize;
ה־DB אינו יוצר run. ה־Cron Route מחזיר HTTP 200 וה־Action מציגה הודעת cooldown
ייעודית בעברית במקום failure כללי.

לא השתנתה סכימת DB או חתימת RPC, ולכן לא נדרש generation של טיפוסי Supabase.

## Regression חדש

- `sports sync claim row contract > parses the real RPC FORCE_COOLDOWN row as a neutral no-run claim`
- `sports sync claim row contract > rejects a cooldown row that claims to have persisted a run`
- `shared sports sync orchestration > returns a forced cooldown skip without provider I/O or a finalizer call`
- `POST /api/cron/sync > returns FORCE_COOLDOWN as a neutral skip without exposing credentials`
- `sports sync trigger action > returns neutral cooldown copy without presenting the valid skip as a failure`
- `sync run display semantics > uses neutral labels for every current skip outcome`
- pgTAP: `FORCE_COOLDOWN creates no sync history row`
