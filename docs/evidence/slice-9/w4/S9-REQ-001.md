## Checkpoint 3 — manual start and existing-Cron activation fallback

Added a forward activation migration, exact-manager `start_league` RPC and
manager UI action. The existing `/api/cron/sync` now calls the service-role
`activate_due_leagues` RPC after authentication/body validation but before
provider environment parsing, provider branching, claim or I/O. The two-minute
database lookahead covers the documented one-minute Cron cadence. On-time rows
persist status, scoring lock and audit before kickoff; a delayed tick stores the
first kickoff as `activated_at`, retains the real audit write time and records
`ACTIVATION_PERSIST_LATE`, which is counted separately and is not accepted as a
deadline success. Manual/provider fixture writers share the lifecycle advisory
lock and the canonical league-before-match order.
