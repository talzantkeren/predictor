# S9-DEF-020 — ראיית escape בטוח מ־invite unavailable

תאריך הרצה: 27.8.2026  
סביבה: branch `feature/slice-9-implementation`, Supabase מקומי ו־production build מקומי. לא נחשפו tokens, cookies, invite secrets או payloads.

## תיקון ורגרסיה

מסלול ההזמנה מאמת session בשרת ומעביר למצבי unavailable רק node של `AppHeader` שנוצר בשרת. רכיב ה־unavailable עצמו אינו מקבל שם ליגה, מזהה ליגה, סטטוס בקשה או נתון משאב אחר. אורח ממשיך לקבל הודעה אטומה וקישור לעמוד הראשי; רק session מאומת מקבל את ניווט היישום הקיים, לרבות Dashboard ו־logout.

הרגרסיה `assertUnavailableInviteNavigation` בתוך `Slices 3 and 4 invite, proof, and manager decision` מכסה בפועל malformed, expired ו־revoked עבור guest ועבור authenticated. בכל מצב נבדקים גם keyboard skip ויעד main יחיד דרך `assertInviteSkipTarget`. ה־spec רץ בשני פרויקטי Playwright: Desktop Chrome ו־Pixel 5.
