## תיקון ורגרסיות

- `admin/matches/loading` ו־`admin/sync/loading` הם busy regions בעלי שם, עם animation רק תחת `motion-safe` וללא live region כפול.
- שגיאת סיבת דחייה מחוברת ל־textarea באמצעות `aria-invalid`, ‏`aria-describedby` help+error ו־`aria-errormessage`; לאחר תשובת שרת שגויה ה־focus חוזר ל־textarea.
- field error אינו live region נוסף; נשאר alert כללי יחיד.
- Playwright מודד focus indicator, יחס contrast של טקסט כפתור הדחייה ≥4.5 ויעד מגע 44×44 CSS px לפחות.

שמות הרגרסיה:

- `admin loading accessibility contracts > names the busy matches region without a duplicate live announcement`;
- `admin loading accessibility contracts > names the busy sync region without a duplicate live announcement`;
- `Slices 3 and 4 invite, proof, and manager decision > rotates a one-time invite, resumes Auth, preserves proof history, and blocks IDOR` — server-invalid rejection, focus/description/live-count/contrast/target assertions.

## בדיקת native 200% — לא נסגרה

בוצעה בדיקה מקומית ב־Codex in-app Browser על build production. נקודת המוצא שנצפתה הייתה `innerWidth=1280`, ‏`devicePixelRatio=1`, ללא overflow. לאחר focus בעמוד וחמש הפעלות של native zoom shortcut (`Ctrl`+`+`, גם `Ctrl`+`Shift`+`+`) הערכים נשארו זהים. ה־browser surface אינו חושף zoom capability, ולכן אין לטעון שנבדק native 200%; לא הוחל CSS zoom כתחליף.

### OWNER ACTION REQUIRED

על owner לפתוח ב־Chrome את ה־Production build של candidate SHA, דרך תפריט Chrome להגדיר **Zoom = 200%** (לא CSS zoom ולא device emulation), ולהריץ עם משתמש Demo חד־פעמי ומחיקת הנתונים לאחר מכן:

1. `/admin/matches` ו־`/admin/sync`: להאט רשת, לטעון מחדש ולאמת באמצעות accessibility tree שלכל loading main יש `busy=true` ושם יחיד; אין announcement כפול.
2. `/leagues/<owned-league>/members` עם בקשה `pending_approval`: לשלוח סיבה באורך חוקי שנדחית בשרת, לאמת focus גלוי על textarea, תיאור help+error, `invalid=true` ו־alert יחיד.
3. למדוד את כפתורי approve/reject: לפחות 44×44 CSS px; לאמת contrast AA, keyboard בלבד, RTL וללא horizontal overflow.
4. לחזור ברוחב חלון פיזי שמניב אזור תוכן mobile וב־desktop, לצרף צילום מסך מצונזר + accessibility snapshot/measurements, candidate SHA, גרסת Chrome והפקודה/צעדים המדויקים לראיה זו.
