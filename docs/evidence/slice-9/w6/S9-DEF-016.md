# S9-DEF-016 — ראיית skip link במסלול הזמנה

תאריך הרצה: 27.8.2026  
סביבה: branch `feature/slice-9-implementation`, Supabase מקומי ו־production build מקומי. לא נעשה שימוש בסוד או בנתוני provider.

## תיקון ורגרסיה

נוסף רכיב skip משותף ל־shell הרגיל ולמסלול ההזמנה. בכל מצב של המסלול קיים בדיוק יעד `main-content` אחד עם `tabIndex=-1`; אורח מקבל את אותו skip link בלי לקבל ניווט משתמש מחובר, ומשתמש מחובר מקבל אותו דרך `AppHeader` בלבד.

שם הרגרסיה: `assertInviteSkipTarget` בתוך `Slices 3 and 4 invite, proof, and manager decision`. היא מפעילה keyboard בפועל: `Tab` ממקד את קישור הדילוג, מאמתת שהקישור בתוך viewport, `Enter` ממקד את יעד ה־main, ומאמתת ספירה יחידה של הקישור והיעד. הקריאות מכסות:

- guest + unavailable;
- guest + valid;
- authenticated + valid;
- authenticated + unavailable.

אותו spec רץ בשני פרויקטי Playwright: Desktop Chrome ו־Pixel 5.
