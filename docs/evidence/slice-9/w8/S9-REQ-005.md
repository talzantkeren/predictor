## Outcome

The Hosted read found a real compatibility defect: the application accepted
passwords up to 128 JavaScript characters, while the active GoTrue v2.195.0
service has a hard 72-byte ceiling. The application now requires at least eight
characters and at most 72 UTF-8 bytes, with ASCII and Hebrew boundary tests and
matching input attributes. Canonical security and technical-plan documents were
updated in the same code change.

The initial Security Advisor export contained 28 items and the Performance
Advisor export contained 20. Every item has an explicit disposition in:

- `S9-REQ-005-security-advisor.md` — 28/28 initial items; 26 post-fix items.
- `S9-REQ-005-performance-advisor.md` — 20/20 items.
- `S9-REQ-005-hosted-auth-policy.md` — exact allowlisted Auth/rate fields and
  the `S9-TDEC-004` accepted-risk record.

One Advisor defect required schema work. Hosted had an RLS event-trigger helper
`public.rls_auto_enable()` with direct `anon` and `authenticated` execution and
a non-empty search path. The definition, owner, ACL and active `ensure_rls`
dependency were inspected before change. The forward-only migration
`20260825000000_revoke_rls_event_trigger_rpc_access.sql` preserves the event
trigger, sets `search_path=''`, and revokes `PUBLIC`, `anon`, `authenticated`
and `service_role` execution. Its pgTAP test covers the security mode, path,
trigger linkage and all four privilege boundaries when the Hosted helper exists.
