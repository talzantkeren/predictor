# S9-DEF-009 — ראיית AuthZ מדויק ו־keyset pagination

תאריך: 27.8.2026

סטטוס: `VERIFIED` על בסיס ה־session הנוכחי בלבד.

סביבה: Supabase מקומי שנבנה מחדש מן ה־migrations ו־Playwright מול Next.js
מקומי. לא נעשתה גישה לפרויקט linked/Hosted, לא הופעל Sports provider חי ולא
נשמרו secrets, cookies, tokens, כתובות Email של fixtures או payloads בראיה.

## החוזה שנבדק

- הרשאת match מדויקת אינה נגזרת עוד מרשימת 200 חברים: הקשר ה־match והליגה
  נבדק עבור המשאב המבוקש, ולכן חבר חוקי נשאר מורשה גם מחוץ לעמוד הראשון;
  משתמש וליגה זרים מקבלים 404 אטום.
- dashboard, בקשות ההצטרפות של המשתמש, תור המנהל, משחקי הליגה, בחירת הליגה
  ל־match, ניחושים שנחשפו ורשימת משחקי מנהל המערכת משתמשים בעמודים bounded עם
  sentinel ו־`hasMore`/cursor במקום להציג hard cap כאילו הוא רשימה מלאה.
- ה־RPCs הציבוריים גוזרים actor מ־`auth.uid()`, משתמשים ב־
  `SECURITY DEFINER` צר עם `search_path = ''`, revoke מ־PUBLIC/anon ו־grant
  רק ל־`authenticated`. תור מנהל דורש הרשאה לליגה המדויקת; בקשות המשתמש אינן
  מקבלות `user_id` מן הלקוח.
- cursors הם keyset יציבים עם tie-breaker UUID. filters של season/status/round
  נשמרים בקישור העמוד הבא; selected league מפורש נבדק בדיוק גם כאשר הוא מחוץ
  לעמוד הבחירה הנוכחי.
- רכיב הדפדוף מציג next/end/empty states, ניתן להפעלה במקלדת, שומר RTL ואינו
  יוצר overflow ב־Desktop Chrome או Pixel 5. יעדי ההפעלה שנבדקו הם לפחות
  44px.
- לא נוסף index ספקולטיבי. בדיקות scale המקומיות מוכיחות 101/201+ reachability
  וחוזי bound; אין במסמך זה claim על Hosted query plan או Advisor.

## regressions חדשים

- `supabase/tests/keyset-pagination.test.sql`: ‏68 assertions ל־ACL, actor
  derivation, exact/cross-league AuthZ, bounds, filters, cursor tie-breakers,
  member/request #101 ומשחקים/חברים מעל hard caps הישנים.
- `supabase/tests/keyset-pagination-concurrency.test.sql`: ‏21 assertions עם
  שלושה חיבורי dblink מחויבים. מנהל דוחה את שורת ה־cursor בין קריאת עמוד ראשון
  לשני; traversal עם timestamp זהה ממשיך בלי gap או duplicate, עם המתנה
  bounded, drain ו־cleanup מחויב.
- `src/lib/keyset-query-contracts.test.ts`: actor-derived RPCs, sentinel bounds,
  filters ו־exact selected league שאינו בעמוד הבחירה.
- `e2e/pagination.spec.ts`: dashboard, own requests, manager queue, admin
  matches, league matches, eligible leagues, revealed predictions, filters,
  empty/end states ו־cross-league opaque denial בשני viewports.
