## סגירת ביקורת עצמאית — נתיבי מפתח מקומיים

כל נתיבי ה־home המוחלטים שנמצאו בפלטי evidence הוחלפו ב־`<repo>` או ב־
placeholder מפורש של runtime מקומי. התוכן הסמנטי, הפקודה ותוצאת הבדיקה נשמרו;
רק מיקום פרופיל המפתח הוסר. `repository-path-hygiene.test.ts` סורק את כל קובצי
הטקסט tracked דרך `git ls-files`, מדלג על binary לפי NUL ומדווח `file:line`
עבור נתיבי macOS/Linux/root/workspace/WSL ו־Windows user-profile. גם דוגמאות
ה־regex מורכבות בזמן ריצה, ולכן קובץ ה־guard עצמו אינו מוחרג מן הסריקה.

```text
npm run test -- src/lib/repository-path-hygiene.test.ts
npm run test -- src/lib/repository-path-hygiene.test.ts
npm run test -- src/lib/repository-path-hygiene.test.ts
npm run lint

Focused run before staging the new guard: 1 file, 6 tests, PASS.
Focused run after staging the guard so it scans its own future tracked source:
1 file, 6 tests, PASS.
Focused run after staging all sanitized evidence: 1 file, 6 tests, PASS.
ESLint: exit 0, no findings.
```

ה־repository-wide assertion היה נכשל על הנתיב שנמצא בביקורת ועל כל שאר נתיבי
הפרופיל שהוסרו. לא נסרק או שונה קובץ binary, ולא בוצעה גישת רשת.
