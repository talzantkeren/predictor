## היקף הסגירה

ה־Hosted canary מוכיח שהפריסה המאושרת בייצור יכולה לתפוס lease, לקרוא, לנרמל
ולהחיל את קטלוג API-Football שפורסם, ולאחר מכן לחזור על אותה עבודה בלי לשכפל
או לשנות שורות. לאחר הסגירה נבדק שוב דף התפעול המורשה והוצגו בו חזרות הקטלוג
וה־reconciliation המוצלחות שמפורטות למעלה.

לא הופעלה ריצת sync ידנית נוספת לצורך האימות. שתי החזרות המוצלחות ללא שינויים
כבר מספקות ראיה מוסמכת לאידמפוטנטיות, וריצה נוספת הייתה צורכת מכסת ספק בלי
להוסיף ראיה חדשה.

## גבול מכוון

צפייה מקצה לקצה במשחק אמיתי שעובר מ־`NS` ל־live ואז ל־`FT` נשארת בדיקה
אופורטוניסטית ולא שער סגירה. הפרויקט אינו מייצר מעבר ספק מלאכותי ב־Hosted.
נעילה, `score.fulltime`, ניקוד דטרמיניסטי, retry, תיקון, ביטול, reactivation
ו־AET/PEN review מכוסים ב־fixtures מוקלטים, Vitest, pgTAP ו־Playwright ללא
תלות ב־API חי ב־CI.

## סינון מידע

המסמך אינו מכיל API key, authorization header, Cron secret, actor ID, cookie,
signed URL, proof path, נתוני משתמש או payload מלא של הספק.
